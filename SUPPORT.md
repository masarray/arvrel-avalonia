# Support

## Preview support

ARVREL Avalonia is an engineering preview provided without a service-level agreement. Use this repository's GitHub issues for reproducible Avalonia defects, cross-platform compatibility problems, migration gaps, and focused feature proposals.

Include:

- commit SHA;
- operating system and architecture;
- desktop environment where relevant;
- source mode;
- minimal synthetic SCL/profile details;
- relevant logs and exact reproduction steps.

For the stable Windows WPF P6 product, use [`masarray/arvrel`](https://github.com/masarray/arvrel).

Community support does not include protection-study approval, operational switching authority, substation cybersecurity assessment, IEC conformance certification, or emergency response for production systems.

## Commercial support

Separately negotiated services may include integration engineering, training, prioritized maintenance, private features, OEM terms, or technical workshops. See [`COMMERCIAL-LICENSING.md`](COMMERCIAL-LICENSING.md).

A commercial engagement exists only after a written agreement is signed. Public issues do not create an SLA or warranty.

## Safe diagnostic material

Use synthetic or contributor-owned files. Do not publish customer captures, proprietary SCL files, credentials, IP plans, station names, or employer-confidential information.
