# UX validation checklist

- Relay F1–F5, RESET, D-pad, OK, Home, Menu, Back, and Favorite retain a dark hardware surface and light foreground in normal, pointer-over, pressed, and keyboard-focus states.
- The injection tab presents current and voltage output groups without per-row provenance prose.
- All eight virtual channels remain editable and continue to use the existing injection commands and portable laboratory authority.
