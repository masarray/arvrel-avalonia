# ARVREL Avalonia 0.1.0-preview.1

Engineering preview of the cross-platform ARVREL desktop migration.

## Included

- Avalonia-native desktop shell;
- internal virtual-injection laboratory;
- process-bus live/replay workspace;
- protection, trust, annunciation, operation-record, and evidence projection;
- self-contained package contracts for Windows x64, Linux x64, and macOS ARM64.

## Status

This preview is not the stable ARVREL release and does not replace the Windows WPF P6 product in `masarray/arvrel`.

Packages are unsigned engineering artifacts. macOS output is ad-hoc signed and not notarized. Live capture remains subject to platform backend availability and operating-system permissions.

## Safety boundary

Virtual output only. No physical trip contact, operational GOOSE trip, MMS control, switching authority, calibration claim, IEC 61850 conformance claim, IEC 60255 type-test claim, or deterministic hard-real-time guarantee is provided.
